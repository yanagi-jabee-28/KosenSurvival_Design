# Archive / 不要ファイル保管フォルダ

このフォルダは、現在は不要だが将来参照する可能性があるファイルや旧バージョンを一時的に保管するための場所です。

利用ルール（推奨）

- **削除ではなく移動**: 大きな変更や削除を行う前に、該当ファイルをここへ移動してください（コミット時に理由を明記）。
- **命名規則**: ファイル名に移動日と短い理由を付ける（例: `old_scene_v1_2026-01-08.md`）。
- **小分けフォルダ**: 必要に応じて `doc/`, `game/`, `src/` などのサブフォルダを作成してください。
- **大容量ファイル**: ビルド成果物やバイナリは基本的に含めないでください。含める場合は理由とサイズをREADMEに追記してください。
- **復元手順**: Gitで復元する場合は `git mv` で戻すか、元の場所へ手動で移動してコミットしてください。

注意事項

- 長期的に不要と判断したものは、別途削除ポリシーに従って永久削除してください。
- このフォルダは参照用であり、不要ファイルを放置するためのごみ箱ではありません。

---

必要なら、次のアクションとして以下を行えます：
- サブフォルダの作成（`doc/`, `game/`, `src/` など）✅
- 既存の不要ファイルの移動を手伝う（指定されたファイルを移動）🔧
