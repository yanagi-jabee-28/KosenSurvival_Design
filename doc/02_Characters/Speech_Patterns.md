# キャラクター口調・性格統一基準 (Speech Patterns & Personality Guidelines)

> **目的**: 各キャラクターの台詞作成時に参照し、口調・性格・語尾・一人称の一貫性を保つ。

## 0. 台詞作成の大原則

### 0.1 必須参照ルール
**新しい台詞を考える際は、必ず以下を参照すること:**
1. 本ファイル ([Speech_Patterns.md](Speech_Patterns.md)) で口調・一人称・語尾を確認
2. 該当キャラクターの個別ドキュメント ([02_Characters/キャラクター名.md]) で性格・背景・関係性を確認
3. 既存シナリオファイル ([03_Scenario/YearX.md]) で文脈と時系列を確認

### 0.2 一貫性チェックリスト
台詞を書く前に以下を自問すること:
- ✅ 一人称は正しいか？（ミナは「俺」、アイは「私」など）
- ✅ 語尾・口調は統一されているか？（ミナは「〜だよ」「〜だな」、アイは「〜です」「〜だ」）
- ✅ 性格と台詞が矛盾していないか？（アイが感情的になりすぎていない、マイが冷静すぎないなど）
- ✅ 関係性に応じた距離感か？（Year 1の初対面とYear 5の親密度MAXでは話し方が変わる）

### 0.3 自然さの基準
- **過度な定型句を避ける**: 毎回同じフレーズの繰り返しは不自然（「〜だよね」を連発しない）
- **文脈に応じた変化**: 緊張時・リラックス時・怒り時で表現が変わることを許容
- **キャラ崩壊を避ける**: 核心的特徴（ミナの職人気質、アイの論理性、レンの皮肉など）は崩さない

## 1. 主要キャラクター口調一覧

### 1.1 赤坂 ミナ (Akasaka Mina) - [職人]
**性格**: 直感型ものづくりオタク。実直で裏表がない。理屈より手を動かす。

| 項目 | 内容 |
|:---|:---|
| **一人称** | 俺 |
| **二人称** | お前、あんた（親しみ）、君（やや距離）、先輩/先生（敬意） |
| **語尾** | 〜だよ、〜だな、〜じゃん、〜っしょ |
| **文体** | カジュアル、短文、断定的 |
| **特徴的な表現** | 「おう！」「マジで？」「やべえ」「っしゃ！」「サンキュー」 |
| **避けるべき表現** | 長文、敬語（目上以外）、論理的説明、丁寧語 |
| **感情表現** | ストレート。嬉しい時は笑顔全開、困った時は素直に困る |

**台詞例:**
- Year 1 初対面: 「おう、初心者か？ じゃあこのドライバー使えよ」
- Year 3 親密度中: 「お前と作ってると、楽しいんだよな」
- Year 5 告白前: 「理屈はわかんねえけど、お前と作るのが一番楽しい」
- 困惑時: 「え、マジで？ やべえじゃん……」
- 興奮時: 「っしゃ！ 動いたぞ！ 見ろよこれ！」

### 1.2 一ノ瀬 アイ (Ichinose Ai) - [天才]
**性格**: 冷徹な合理主義者。論理至上。感情表現が苦手だが、本当は孤独を感じている。

| 項目 | 内容 |
|:---|:---|
| **一人称** | 私 |
| **二人称** | 貴方（基本）、君（やや距離）、あなた（親密時） |
| **語尾** | 〜です、〜だ、〜ね（稀）、〜わ（極稀、親密時のみ） |
| **文体** | 簡潔、論理的、感情を排した断定 |
| **特徴的な表現** | 「論理的に考えれば」「証明できない」「当然」「理解不能」 |
| **避けるべき表現** | 感嘆詞（「わあ」「やった」など）、幼稚な語彙、曖昧な表現 |
| **感情表現** | ほぼ無表情。親密度が上がると微かに笑う、照れる（言葉には出さない） |

**台詞例:**
- Year 1 初対面: 「貴方の論理展開には穴がある。もう一度考えなさい」
- Year 2 協力時: 「制御プログラムのバグね。ここを修正しなさい」
- Year 3 親密度高: 「この定理の証明は、まるで詩のように美しい。……貴方にも見えるか？」
- Year 5 告白: 「貴方は私の唯一の理解者。……証明終了（Q.E.D.）」
- 困惑時（親密時のみ）: 「……それは、私にも分からない」

### 1.3 諏訪野 レン (Suwano Ren) - [支配者]
**性格**: 冷静沈着な皮肉屋。感情を表に出さず、常に合理性で判断。他人を見下す傾向。

| 項目 | 内容 |
|:---|:---|
| **一人称** | 俺 |
| **二人称** | 君、お前（見下し）、貴方（敬意なし）、先輩（形式的） |
| **語尾** | 〜だ、〜だな、〜だろう |
| **文体** | 低温、皮肉混じり、簡潔 |
| **特徴的な表現** | 「……まあいい」「覚えておこう」「使えないな」「才能あるな」 |
| **避けるべき表現** | 感情的な言葉、褒め言葉（稀に使うが機械的）、温かみのある表現 |
| **感情表現** | 皮肉な笑み、冷たい目線。認めた相手にだけ僅かに評価を示す |

**台詞例:**
- Year 1 初遭遇: 「君、ここに何の用だ？ ……まあいい。覚えておこう」
- Year 2 評価時: 「お前、才能あるな。来年も仕事を任せるかもしれない」
- Year 3 継承時: 「お前が、次の支配者だ。好きに使え」
- 失望時: 「残念だが、お前には無理だ」
- クエスト失敗: 「使えないな。次はもっとマシな奴を探すか」

### 1.4 神楽 マイ (Kagura Mai) - [リーダー]
**性格**: 冷静沈着で負けず嫌い。論理的だが、信頼する相手には温かみを見せる。完璧主義。

| 項目 | 内容 |
|:---|:---|
| **一人称** | 私 |
| **二人称** | あなた、君（公的）、お前（親密時のみ）、先輩/先生（敬意） |
| **語尾** | 〜です、〜ます（公的）、〜だ、〜ね（親密時） |
| **文体** | 丁寧かつ簡潔。親密度が上がると砕けた表現も |
| **特徴的な表現** | 「よろしくお願いします」「ありがとう」「一緒に頑張りましょう」 |
| **避けるべき表現** | 幼稚な語彙、過度なフレンドリーさ（初対面時）、弱音（親密度低時） |
| **感情表現** | 基本は冷静。親密度が上がると笑顔、弱音を見せる |

**台詞例:**
- Year 1 初対面（スカウト）: 「あなた、学生会に興味ない？」
- Year 2 弱音（親密時）: 「私、本当に会長の器なのかな……」
- Year 3 対等認定: 「あなたは私の対等なパートナーだ」
- Year 5 告白: 「あなたと一緒なら、どんな未来も乗り越えられる気がする」
- 緊張時: 「……大丈夫。落ち着いて。私たちならできる」

### 1.5 室井 禅 (Muroi Zen) - [留年王]
**性格**: 飄々として達観した皮肉屋。「時間は幻想」が口癖。人の野心を見透かす。

| 項目 | 内容 |
|:---|:---|
| **一人称** | 俺、僕（気分次第） |
| **二人称** | 君、お前（親密時）、貴方（皮肉） |
| **語尾** | 〜だよ、〜だね、〜かな |
| **文体** | 囁くよう、淡々、時々少年のような軽さ |
| **特徴的な表現** | 「時間は幻想」「贅沢は浪費してこそ」「立ち止まって沼に足を浸けてみないか」 |
| **避けるべき表現** | 焦り、熱意、目標設定、未来への言及（覚醒イベント以外） |
| **感情表現** | 薄笑い、達観。覚醒時のみ少年のような無邪気さ |

**台詞例:**
- Year 1 初遭遇: 「……何も変わらないことが、こんなに心地いいなんて」
- Year 2 誘惑: 「君は急ぎすぎている。立ち止まって、沼に足を浸けてみないか」
- Year 4 真実: 「時間は贅沢品だ。贅沢は、浪費してこそ贅沢だ」
- Year 5 分岐: 「一緒に残ろう。……外に出るのは怖い。けど、君が行くなら……少しだけ歩こうか」
- 皮肉: 「卒業？ そんなもの、幻想だよ」

### 1.6 剛田 タケシ (Gouda Takeshi) - [逸脱]
**性格**: 陽気なサボり魔。楽観的だが、追い詰められると心が折れやすい。

| 項目 | 内容 |
|:---|:---|
| **一人称** | 俺 |
| **二人称** | お前、あんた、先輩/先生（敬意） |
| **語尾** | 〜だぜ、〜じゃん、〜っしょ、〜かよ |
| **文体** | カジュアル、軽い、時々弱気 |
| **特徴的な表現** | 「やべえ」「マジか」「無理っしょ」「助けてくれよ」 |
| **避けるべき表現** | 論理的説明、長文、真面目すぎる台詞 |
| **感情表現** | 明るく軽い。追い詰められると一気に暗くなる |

**台詞例:**
- Year 1 初対面: 「よお！ 俺、剛田タケシ。よろしくな！」
- Year 1 Week 15（危機）: 「やべえ……マジで留年すんのか……？」
- 救済時: 「お前……本当にありがとな。俺、お前がいなきゃダメだったわ」
- サボり誘惑: 「今日の授業サボって、ゲームしようぜ！」
- 退学後: 「俺、もう無理だわ……」

### 1.7 若葉 ユズ (Wakaba Yuzu) - [成長株]
**性格**: 無邪気で素直。主人公を慕う後輩。模倣学習で成長する。

| 項目 | 内容 |
|:---|:---|
| **一人称** | 私 |
| **二人称** | 先輩、〜さん（敬意）、あなた（親密時） |
| **語尾** | 〜です、〜ます、〜ですね、〜ですよ！ |
| **文体** | 明るく丁寧、やや幼い |
| **特徴的な表現** | 「先輩すごいです！」「私も頑張ります！」「教えてください！」 |
| **避けるべき表現** | 冷たい言葉、皮肉、複雑な論理 |
| **感情表現** | 笑顔、目を輝かせる。落ち込むと分かりやすく沈む |

**台詞例:**
- Year 2 初対面: 「先輩！ 私、先輩みたいになりたいです！」
- Year 3 模倣: 「先輩がいつもやってること、私も真似してます！」
- Year 4 成長: 「先輩、見てください！ できるようになりました！」
- Year 5 告白: 「先輩……ずっと一緒にいてくださいね」
- 失敗時: 「ごめんなさい……私、まだまだですね……」

## 2. 口調の時系列変化ガイドライン

### 2.1 Year 1（初対面）
- **距離感**: 基本的に敬語、または軽い丁寧語
- **例外**: ミナは初対面から「俺/お前」、レンは「君」で距離を置く

### 2.2 Year 2-3（関係構築）
- **距離感**: 親密度に応じて砕けていく
- **アイ**: 「貴方」→「あなた」、「〜だ」が増える
- **マイ**: 「〜です」→「〜だね」、「君」→「お前」（親密時のみ）

### 2.3 Year 4-5（親密期）
- **距離感**: 最も砕けた表現、感情的な台詞が増える
- **全キャラ共通**: 弱音や本音を見せる、笑顔が増える

## 3. シーン別口調ガイド

### 3.1 初対面シーン
- **基本**: 丁寧語または軽い挨拶
- **NG**: いきなり親しすぎる、いきなり弱音

### 3.2 日常会話シーン
- **基本**: キャラ固有の口調を維持
- **NG**: 全員が同じ口調になる

### 3.3 緊張・危機シーン
- **基本**: 語気が強まる、短文になる、感情が表に出る
- **例**: ミナ「やべえ！」、アイ「……まずい」、マイ「落ち着いて！」

### 3.4 親密・告白シーン
- **基本**: 感情的な表現が増える、普段使わない語尾も許容
- **例**: アイ「……好き、だ」（普段は言わない断定）、マイ「お前がいなきゃダメなんだ」

## 4. NG台詞パターン集

### 4.1 全キャラ共通NG
- ❌ 「〜だよね、〜だよね、〜だよね」（同じ語尾の連続）
- ❌ 「えっと……あの……その……」（過度な口ごもり）
- ❌ 「私たち、頑張りましょう！」（全員が同じ励まし）

### 4.2 キャラ別NG
| キャラ | NG台詞例 | 理由 |
|:---|:---|:---|
| ミナ | 「理論的に考えればですね……」 | 論理的すぎる |
| アイ | 「やったー！ 嬉しい！」 | 感情表現が幼稚 |
| レン | 「一緒に頑張ろう！」 | 熱意がありすぎる |
| マイ | 「マジやばくね？」 | カジュアルすぎる（Year 1-2） |
| 禅 | 「卒業目指して頑張ろう」 | 目標設定が明確すぎる |

## 5. 参照手順（実践ガイド）

### 台詞作成フロー
1. **キャラクター特定**: 誰の台詞を書くか明確にする
2. **時系列確認**: Year 1-5のどの時期か確認
3. **関係性確認**: 主人公との親密度レベルを確認
4. **口調参照**: 本ファイルの該当キャラセクションを開く
5. **個別ドキュメント参照**: [02_Characters/キャラクター名.md] で性格・背景を再確認
6. **既存台詞参照**: [03_Scenario/YearX.md] で類似シーンの既存台詞を確認
7. **台詞作成**: 一人称・語尾・文体を統一して作成
8. **チェックリスト確認**: 0.2節のチェックリストで検証
9. **自然さ確認**: 声に出して読み、不自然でないか確認
